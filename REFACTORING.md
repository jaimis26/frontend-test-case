# Описание внесенных изменений и решенных проблем

В ходе рефакторинга я разделил логику и интерфейс на независимые части, убрал дублирование данных и исправил несколько ошибок в работе компонентов. Внешний вид и исходные стили `App.css` полностью сохранены.

## 1. Улучшения в Redux Toolkit (`src/store/`)
* **Разделил один большой слайс на три независимых:** вместо общего `appSlice` создал отдельные слайсы для товаров (`productsSlice`), корзины (`cartSlice`) и пользователя (`userSlice`). Так код проще читать и поддерживать.
* **Убрал дублирующиеся поля из стейта корзины:** раньше в сторе хранились 5 лишних полей (`cartCount`, `totalPrice`, `cartItemsCount`, `cartTotalAmount`, `cartTotalSum`), которые пересчитывались вручную в каждом редьюсере. Я удалил их из стейта и перенес подсчет количества и итоговой суммы в селекторы (`createSelector`).
* **Вынес имитацию загрузки данных в `createAsyncThunk`:** перенес `setTimeout` с загрузкой товаров и профиля пользователя из компонентов в `fetchProducts` и `fetchUser`. Также добавил обработку состояний загрузки (`loading`) и ошибок (`error`).
* **Заменил строковые экшены:** вместо ручного создания объектов `{ type: 'app/addToCart' }` везде используются готовые action creators, импортированные из слайсов.

## 2. Разбиение компонентов и улучшения в React (`src/components/`)
* **Разбил большой `App.jsx` на отдельные компоненты:** вынес шапку (`Header`), каталог (`ProductList`), карточку товара (`ProductCard`), корзину (`Cart`) и элемент корзины (`CartItem`) в свои файлы.
* **Перенес `<Provider store={store}>` в `main.jsx`:** чтобы корневой компонент `App.jsx` отвечал только за общую разметку страницы.
* **Оптимизировал фильтрацию и сортировку:** обернул вычисление списка отфильтрованных товаров в `useMemo`, чтобы список не пересчитывался лишний раз при нажатии на другие кнопки.
* **Починил кнопку «Показать/Скрыть фильтры»:** раньше состояние `showFilters` менялось при клике, но ни на что не влияло. Теперь кнопка действительно скрывает и показывает выбор категории и сортировки.
* **Убрал `alert()` при оформлении заказа:** заменил стандартное всплывающее окно браузера на сообщение об успешном заказе внутри самой корзины.

## 3. Организация проекта
* **Вынес тестовые данные и списки в отдельный файл:** массив товаров, данные пользователя и опции для фильтров перенесены из компонентов в `src/constants/mockData.js`.
